# 会場情報の掲載と、運営への確認事項

「ピアノひろば」の公開ページ（トップページ・予約完了画面）に表示する会場情報の設定方法と、
掲載にあたって運営側で確認が必要な項目をまとめています。

表示は `src/components/VenueInfo.tsx`、値は `src/lib/config.ts`（環境変数で上書き可能）で管理しています。

## 1. 現在掲載している内容（確認済み）

| 項目 | 値 | 設定元 |
|---|---|---|
| 会場名 | 株式会社田中組 本社 1階ホール（指定エリア） | `VENUE_NAME` |
| 住所 | 北海道札幌市中央区北6条西11丁目26番地 | `VENUE_ADDRESS` |
| 地図を開くリンク | 住所から自動生成（Googleマップ検索） | `VENUE_MAP_URL`（設定時はそちらを優先） |
| 当日の受付方法 | 受付でQRコード・予約番号を提示、またはお名前を伝える | `config.venueChecklist` |

## 2. 運営への確認事項（未確認のため公開画面に掲載していない）

以下は推測で記載せず、**公開画面には表示していません**。確認が取れ次第、対応する環境変数を設定すると、
トップページ・予約完了画面の「会場のご案内」に自動的に表示されます（未設定の項目は非表示のまま、
代わりに問い合わせ先の案内が表示されます）。

| 確認したい項目 | 設定する環境変数 | 確認のポイント |
|---|---|---|
| 最寄り駅・バス停からのアクセス | `VENUE_ACCESS` | 最寄り駅・バス停の名称、徒歩の所要時間、目印になる建物 |
| 建物の入口と受付場所 | `VENUE_ENTRANCE` | どの入口から入るか（正面玄関／通用口）、受付の場所、来場時に声をかける相手 |
| 駐車場・駐輪場の有無 | `VENUE_PARKING` | 利用可否、台数、料金、満車時の案内（近隣コインパーキング等の可否） |
| 段差・車いすでのご来館 | `VENUE_ACCESSIBILITY` | 入口の段差の有無、スロープ・エレベーターの有無、多目的トイレ、事前連絡の要否 |
| 会場名の正式表記 | `VENUE_NAME` | 「本社 1階ホール」という表記で利用者に伝わるか（館名・フロア名の正式名称） |
| 入口・受付の写真 | （画像を `public/` に追加して掲載） | はじめての方が来場の流れを想像できる写真があると望ましい |

### 設定例

```
VENUE_ACCESS="JR◯◯駅から徒歩◯分／市営バス「◯◯」停留所から徒歩◯分"
VENUE_ENTRANCE="正面玄関からお入りいただき、1階受付にお声がけください"
VENUE_PARKING="来客用駐車場を◯台ご用意しています（無料）。駐輪場は正面玄関横です"
VENUE_ACCESSIBILITY="入口に段差はありません。車いすでのご来館も可能です"
```

## 3. FAQ の内容について確認したい点

トップページの「よくあるご質問」には、利用規約（`/terms`）および
[運用マニュアル](./OPERATIONS.md) と矛盾しない範囲で回答を掲載しています。
次の2点は運営方針として明文化されていないため、実際の運用と合っているかご確認ください。

- **同伴者の人数** — 現在は「ご家族・お連れの方の入場は可能。スペースに限りがあるため少人数で」と案内しています。
  上限人数を設ける場合は、FAQ（`src/app/page.tsx` の `FAQ`）と利用規約の記載を合わせてください。
- **楽譜の貸し出し** — 現在は「貸し出しは行っていないため持参いただく」と案内しています。
  会場に備え付けの楽譜がある場合は記載を変更してください。

## 4. 当日の受付運用との整合

サイト上は「QRコード・予約番号の提示、またはお名前の申告」で受付できると案内しています
（[運用マニュアル](./OPERATIONS.md) 2-2 の「QRコードを提示できない場合は、予約番号または氏名で検索して手動チェックイン」に対応）。
受付の運用を変更する場合は、以下の表示も合わせて見直してください。

- `src/lib/config.ts` の `venueChecklist`
- トップページ「ご利用の流れ」4番目のステップ、FAQ「QRコードを表示できない場合」
- 利用規約 第2条1（`src/app/terms/page.tsx`）
- 予約完了画面の案内（`src/app/reserve/complete/[id]/page.tsx`）
