# 会場情報の掲載と、運営への確認事項

「ピアノひろば」の公開ページ（トップページ・予約完了画面）に表示する会場情報の設定方法と、
掲載にあたって運営側で確認が必要な項目をまとめています。

表示は `src/components/VenueInfo.tsx`、値は `src/lib/config.ts`（環境変数で上書き可能）で管理しています。

## 2. 運営への確認事項（未確認のため公開画面に掲載していない）

以下は推測で記載せず、**公開画面には表示していません**。確認が取れ次第、対応する環境変数を設定すると、
トップページ・予約完了画面の「会場のご案内」に自動的に表示されます（未設定の項目は表示されず、
その項目名を挙げて「準備でき次第掲載します」と問い合わせ先が案内されます）。

| 確認したい項目 | 設定する環境変数 | 確認のポイント |
|---|---|---|
| 段差・車いすでのご来館 | `VENUE_ACCESSIBILITY` | 入口の段差の有無、スロープ・エレベーターの有無、多目的トイレ、事前連絡の要否 |
| 駐輪場・駐車台数・料金 | `VENUE_PARKING`（現在の文面に追記） | 駐輪場の有無と場所、来客用駐車場の台数、無料/有料、満車時の案内 |
| 入口・受付の写真 | 画像を `public/` に追加して掲載 | はじめての方が来場の流れを想像できる写真（外観・正面玄関・無人受付の電話機）。画像ファイルをリポジトリに追加いただければ「会場のご案内」に掲載します |

### 設定例

```
VENUE_ACCESSIBILITY="入口に段差はありません。車いすでのご来館も可能です"
VENUE_PARKING="敷地内の来客用駐車場（無料・◯台）をご利用いただけます。駐輪場は正面玄関横です"
```

### 入口・駐車場の位置の表現について

写真では正面玄関と来客用駐車場が隣接しています。「左・右」は来場者がどちらから来るかで向きが変わるため、
公開画面では左右を使わず「1階のガラス張りの正面玄関」「敷地内の来客用駐車場」と表現しています。
「正面玄関に向かって右側が駐車場」のように起点を明示した表現に変更したい場合は `VENUE_ENTRANCE` /
`VENUE_PARKING` を書き換えてください。

## 3. FAQ の内容（確認済み）

トップページの「よくあるご質問」は、利用規約（`/terms`）および [運用マニュアル](./OPERATIONS.md) と
矛盾しない内容で掲載しています。次の2点は運営に確認済みです。

- **同伴者の人数** — 上限は設けず、「ご家族・お連れの方の入場は可能。スペースに限りがあるため少人数で」と案内（2026年9月確認）。
- **楽譜の貸し出し** — 行っていないため持参いただく案内（2026年9月確認）。

変更する場合は `src/app/page.tsx` の `FAQ` を編集してください。

## 4. 当日の受付運用との整合

サイト上は「QRコード・予約番号の提示、またはお名前の申告」で受付できると案内しています
（[運用マニュアル](./OPERATIONS.md) 2-2 の「QRコードを提示できない場合は、予約番号または氏名で検索して手動チェックイン」に対応）。
受付は無人のため、来場者には内線「9501」（総務部）での呼び出しを案内しています。
受付の運用を変更する場合は、以下の表示も合わせて見直してください。

- `src/lib/config.ts` の `venueChecklist`（受付方法）と `venueEntrance`（入口・受付の呼び出し方）
- トップページ「ご利用の流れ」4番目のステップ、FAQ「QRコードを表示できない場合」
- 利用規約 第2条1（`src/app/terms/page.tsx`）
- 予約完了画面の案内（`src/app/reserve/complete/[id]/page.tsx`）
- 予約確認・リマインダー・日時変更・繰り上げの各メール（`src/lib/email/templates.ts`）
