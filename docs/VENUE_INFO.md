掲載にあたって運営側で確認が必要な項目をまとめています。

表示は `src/components/VenueInfo.tsx`、値は `src/lib/config.ts`（環境変数で上書き可能）で管理しています。

## 2. 掲載写真について

`src/components/VenueInfo.tsx` の `PHOTOS` で2枚を掲載しています。差し替える場合は、同じファイル名で
`public/` の画像を置き換えるか、`PHOTOS` の `src` / `width` / `height` / `alt` / `caption` を更新してください。

| ファイル | 内容 | キャプション |
|---|---|---|
| `public/venue-entrance.jpg` | 本社の外観（看板・来客用駐車場・正面玄関） | 「株式会社田中組」の看板が目印です。手前が来客用駐車場・駐輪場、奥のひさしの下が正面玄関です。 |
| `public/venue-reception.jpg` | 1階受付の内線電話機と内線番号の案内板 | 受付は無人です。台の上の電話機で内線「9501」（総務部）をお呼び出しください。 |

**受付の写真は、ゲストWi-FiのSSID・パスワード・QRコードが写った案内板が入らない範囲に切り出して掲載しています**
（`public/` に置いた画像は誰でも直接URLで閲覧できるため）。元の画像はGitの履歴（コミット `f226861`）に残っています。
Wi-Fiの案内板を含む元の写真を掲載したい場合は、`public/venue-reception.jpg` を差し替えてください。

## 3. 運営への確認事項（残り）

現在、公開画面に未掲載の項目はありません。次の点は掲載内容に含めていないため、必要に応じて追記してください。

| 項目 | 追記先 | 補足 |
|---|---|---|
| 来客用駐車場の台数・満車時の案内 | `VENUE_PARKING` | 現在は台数に触れず「敷地内の来客用駐車場・駐輪場を無料でご利用いただけます。」と案内 |
| 入口の段差の有無・事前連絡の要否 | `VENUE_ACCESSIBILITY` | 現在は「車いすでのご来館が可能です。1階に多目的トイレがございますので、ご自由にご利用ください。」と案内 |

### 設定例

```
VENUE_PARKING="敷地内の来客用駐車場・駐輪場を無料でご利用いただけます（駐車場は◯台）"
VENUE_ACCESSIBILITY="入口に段差はなく、車いすでのご来館が可能です。1階に多目的トイレがございますので、ご自由にご利用ください"
```

## 4. FAQ の内容（確認済み）

トップページの「よくあるご質問」は、利用規約（`/terms`）および [運用マニュアル](./OPERATIONS.md) と
矛盾しない内容で掲載しています。次の2点は運営に確認済みです。

- **同伴者の人数** — 上限は設けず、「ご家族・お連れの方の入場は可能。スペースに限りがあるため少人数で」と案内（2026年9月確認）。
- **楽譜の貸し出し** — 行っていないため持参いただく案内（2026年9月確認）。

変更する場合は `src/app/page.tsx` の `FAQ` を編集してください。

## 5. 当日の受付運用との整合

サイト上は「QRコード・予約番号の提示、またはお名前の申告」で受付できると案内しています
（[運用マニュアル](./OPERATIONS.md) 2-2 の「QRコードを提示できない場合は、予約番号または氏名で検索して手動チェックイン」に対応）。
受付は無人のため、来場者には内線「9501」（総務部）での呼び出しを案内しています。
受付の運用を変更する場合は、以下の表示も合わせて見直してください。

- `src/lib/config.ts` の `venueChecklist`（受付方法）と `venueEntrance`（入口・受付の呼び出し方）
- トップページ「ご利用の流れ」4番目のステップ、FAQ「QRコードを表示できない場合」
- 利用規約 第2条1（`src/app/terms/page.tsx`）
- 予約完了画面の案内（`src/app/reserve/complete/[id]/page.tsx`）
- 予約確認・リマインダー・日時変更・繰り上げの各メール（`src/lib/email/templates.ts`）
