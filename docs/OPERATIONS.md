# 運用マニュアル（現場スタッフ向け）

このドキュメントは、グランドピアノ一般開放プログラムを実施日ごとに運営するスタッフ向けの手引きです。システムの使い方だけでなく、鍵・設備の受け渡し、調律スケジュールとの連携、衛生管理、騒音配慮の声かけなど、コードでは扱えない「人が行う運用」をまとめています。

## 1. 開放日の基本情報

- 開催日: 毎月 第1・第3金曜日
- 時間帯: 16:00〜17:00（10分単位・最大6組）
- 対象: 事前予約制（当日飛び込みは空きがある場合のみ管理画面で確認のうえ対応）

## 2. 当日の運営フロー

### 2-1. 開場前（15:30 目安）

1. 管理画面（`/admin`）にログインし、当日の予約一覧を確認する。
   - 予約者数、未成年同伴の有無、備考欄（アレルギー・配慮事項等）を事前に把握しておく。
2. 会場・鍵の受け渡し
   - 施設管理担当（総務部）から会場の鍵を受け取る。受け渡し記録は各拠点の「鍵貸出簿」に記入する（本システムでは管理しない）。
   - ピアノカバーを外し、椅子の高さ調整用ペダル台を所定の位置に設置する。
3. 受付用の端末（タブレット/スマートフォン）で `/admin/checkin` を開き、QRコードスキャンが可能な状態にしておく。カメラ権限の許可が必要な場合は事前に許可しておく。

### 2-2. 受付・チェックイン

1. 来場者にQRコード（予約完了メールまたは予約完了画面に表示されたもの）を提示してもらう。
2. スタッフが `/admin/checkin` でスキャンし、表示された氏名・時間枠・未成年フラグを目視確認する。
3. 内容が正しければ「この内容で来場確認する」を押して確定する。QRコードを提示できない場合は、予約番号または氏名で管理画面の予約一覧を検索し、手動で来場確認を行う。
4. 未成年（`ageCategory: minor`）の予約は、保護者氏名が登録されているか、または保護者が同伴しているかを必ず確認する。同伴が確認できない場合は演奏を開始せず、その場で保護者へ連絡する。

### 2-3. 演奏中の見守り

- 1組10分。終了1〜2分前にスタッフが声をかけ、次の組の準備を促す。
- 待機列がある場合は、待機者にも受付時に整理番号（予約時刻）を伝え、混乱を防ぐ。

### 2-4. 閉場後

1. 鍵盤・椅子・ペダル周辺を清拭用アルコールシートで拭く（衛生チェックリストは下記4章）。
2. ピアノカバーをかけ、椅子を所定の位置に戻す。
3. 会場の鍵を施設管理担当に返却し、鍵貸出簿に返却時刻を記入する。
4. 管理画面で当日の来場実績（来場済み／未来場）を確認し、無断キャンセルがあれば備考にメモを残す（ノーショー回数はシステムが自動集計するため、手動での加算操作は不要）。

## 3. 調律スケジュールとの連携（休止日の設定）

グランドピアノの調律日や、会場が使えない日（他イベントとの重複等）は、事前に「休止日」として管理画面に登録し、予約枠が表示されないようにします。

1. 調律業者・施設管理担当から調律予定日の連絡を受けたら、担当者は速やかに `/admin/blackout-dates` にアクセスする。
2. 対象日を選択し、理由（例:「調律のため」「施設点検のため」）を入力して登録する。
3. 登録した休止日は、予約ページのカレンダーから自動的に除外され、既に予約が入っている場合は表示上「休止日」として案内される（既存予約がある状態で登録する場合は、事前に予約者へ個別連絡し、振替日を案内すること。システムは既存予約の自動キャンセル・自動連絡は行わない）。
4. 調律業者との連絡は本システム外（電話・メール・既存の業務連絡フロー）で行い、確定した日程のみを休止日として登録する運用とする。

**推奨リードタイム**: 調律日は判明次第、遅くとも対象の金曜日の1週間前までに休止日登録を完了させる（予約者への影響を最小化するため）。

## 4. 衛生管理チェックリスト（毎開催日）

- [ ] 開場前: 鍵盤・鍵盤蓋を除菌シートで清拭
- [ ] 開場前: 椅子（座面・背もたれ）を清拭
- [ ] 開場前: ペダル・ペダル台を清拭
- [ ] 各組終了ごと: 鍵盤の目立つ汚れがあれば都度清拭（特に複数組が連続する場合）
- [ ] 閉場後: 鍵盤・椅子・ペダルを再度清拭し、換気を行う
- [ ] 消耗品（除菌シート・手指消毒液）の残量を確認し、不足があれば総務部に補充を依頼

## 5. 騒音配慮に関するスタッフの声かけ

本プログラムは住宅・オフィスが近接する環境での実施を想定しているため、以下の声かけを徹底してください。

- 予約時に利用者は「音への配慮事項」に同意済みですが、当日も受付時に一言添える:
  「恐れ入りますが、周辺への配慮のため、窓・扉は閉めた状態でご利用いただいております」
- 極端な強打（フォルティッシモの連続等）が周辺から問題視される可能性がある場合は、やんわりと音量への配慮を依頼する。
- 近隣から音に関する問い合わせ・苦情があった場合は、当日の対応記録（日時・内容・対応者）を運営チームの共有ドキュメント（本システム外）に残し、翌営業日中に責任者へ報告する。

## 6. トラブル時の対応

| 状況 | 対応 |
|---|---|
| QRコードが読み取れない | 手動入力欄に予約番号を入力するか、氏名で予約一覧を検索して手動チェックインする |
| 二重予約・システムエラーが疑われる | その場で無理に対応せず、予約者の連絡先を控え、運営責任者に一次報告。管理画面の予約一覧で実際の状態を確認する |
| 来場者が予約時間に遅刻した | 後続の予約に影響しない範囲で対応可否を判断。枠を超えて演奏させない（後続予約者を優先） |
| 無断キャンセルが続く利用者からの当日連絡 | システム上のペナルティ判定に従う（[README](../README.md) のノーショー規定を参照）。個別の例外対応が必要な場合は運営責任者が判断する |
| 管理画面にログインできない | パスワード再発行は開発・運用担当者に連絡（[DEPLOYMENT.md](./DEPLOYMENT.md) 参照） |

## 7. 連絡先・エスカレーション

- 施設・鍵に関する問い合わせ: 総務部（既存の社内連絡フローに従う）
- 調律・設備に関する問い合わせ: 施設管理担当
- システムの不具合・改修依頼: 運用・開発担当者（[DEPLOYMENT.md](./DEPLOYMENT.md) の管理者連絡先を参照）
