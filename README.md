# グランドピアノ一般開放プログラム 予約システム

株式会社田中組が実施するグランドピアノ一般開放プログラム（毎月第1・第3金曜 16:00〜17:00、10分単位・最大6組）向けの、Web予約・QRコード来場管理システムです。

Next.js（App Router）+ TypeScriptで構築されており、データストアはローカルJSONファイル（開発・デモ用）とGoogle Sheets（本番運用用）を切り替え可能なアダプタ構成になっています。

## 主な機能

- **予約導線**: カレンダー形式の日付選択 → 10分単位の空き枠選択 → 予約フォーム → 完了画面（QRコード表示）
- **二重予約防止**: 同一枠への同時リクエストを排他制御し、必ず1件のみ成立させる
- **月間予約上限**: 同一メールアドレスからの月内予約数を制限
- **キャンセル待ち**: 満席枠へのキャンセル待ち登録と、キャンセル発生時の自動繰り上げ・通知
- **セルフサービス管理**: 予約者が確認メール内のリンクから自分でキャンセル・日程変更できる管理画面（`/manage`）
- **QRコード来場確認**: 予約完了時に発行されるQRコードを、当日スタッフが `/admin/checkin` でスキャンして来場確認
- **メール通知**: 予約確認・前日リマインダー・キャンセル・キャンセル待ち登録/繰り上げ・管理者向け新規予約通知
- **ノーショー管理**: 無断キャンセルの回数を記録し、一定回数を超えた利用者の新規予約を一定期間制限
- **休止日（ブラックアウト日）管理**: 調律日・施設点検日等を管理画面から登録し、予約カレンダーから自動除外
- **管理者ダッシュボード**: 予約一覧・来場状況の確認、休止日管理（JWTセッションによる認証保護）
- **未成年配慮**: 未成年の予約時に保護者氏名の入力を必須化し、QRチェックイン時にスタッフへ表示
- **利用規約・プライバシーポリシー**: `/terms` `/privacy` ページ（要法務レビュー、下記「重要な注意事項」参照）
- **個人情報保護**: 一定期間経過後の予約データを氏名・連絡先を匿名化するバッチ（`scripts/purge-old-data.ts`）

## セットアップ（ローカル開発）

```bash
npm install
cp .env.example .env.local
npm run dev
```

`.env.local` を編集しなくても、`STORE_BACKEND=local`（既定値）のままであれば認証情報なしですぐに動作します。予約データは `var/data/db.json` に、メール送信内容は `var/outbox/` にHTMLファイルとして保存されます（実際の送信は行われません）。

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。管理画面は [http://localhost:3000/admin](http://localhost:3000/admin) から、初回起動時に `.env.local` の `ADMIN_EMAIL` / `ADMIN_PASSWORD` で自動作成されたアカウントでログインできます。

> **重要**: `.env.example` に記載のデフォルト管理者パスワード（`changeme123`）は開発用です。本番公開前に必ず変更してください。手順は [docs/DEPLOYMENT.md](./docs/DEPLOYMENT.md) の「3. 管理者アカウントの設定」を参照してください。

## ディレクトリ構成（概要）

```
src/
  app/                Next.js App Router（画面・APIルート）
    reserve/          予約導線（日付→枠→フォーム→完了）
    manage/           予約者向けセルフサービス（キャンセル・変更）
    admin/            管理者ダッシュボード（要ログイン）
    api/              REST APIエンドポイント
  lib/
    config.ts         開催日・時間枠・上限等の業務ルール設定
    dates.ts          「第n金曜日」等の日付計算
    booking.ts        予約作成・キャンセル・キャンセル待ちのコアロジック
    availability.ts   空き状況の計算
    noshow.ts         ノーショー判定・ペナルティ
    qr.ts             QRコード生成
    auth.ts           管理者セッション認証
    email/            メール送信（Resend / コンソール出力の切替）
    store/            データストアのアダプタ（local / sheets）
docs/
  OPERATIONS.md       現場運用マニュアル（鍵の受け渡し・調律連携・衛生管理・騒音配慮）
  DEPLOYMENT.md        Google Sheets/Resend/Vercel連携の設定手順
tests/                Vitestによる自動テスト
scripts/               定期バッチ（個人情報匿名化）
```

## 運用ドキュメント

- [docs/OPERATIONS.md](./docs/OPERATIONS.md) — 開催日当日の現場運用（鍵・設備の受け渡し、調律スケジュール連携、衛生管理チェックリスト、騒音配慮の声かけ、トラブル対応）
- [docs/DEPLOYMENT.md](./docs/DEPLOYMENT.md) — Google Sheets連携・メール送信・Vercelデプロイ・本番公開前チェックリスト

## 重要な注意事項

- **利用規約・プライバシーポリシー（`/terms` `/privacy`）は初期ドラフトです。** 実際の公開前に必ず法務担当者のレビューを受けてください。
- **管理者のデフォルトパスワードは開発用です。** 本番公開前に必ず変更してください（[docs/DEPLOYMENT.md](./docs/DEPLOYMENT.md) 参照）。
- **Google Sheets連携・実メール送信を使うには、実際の認証情報（サービスアカウント・APIキー）の設定が必要です。** 設定なしでは開発用のローカルストア・コンソール出力のみで動作します。

## テスト

```bash
npm run test
```

二重予約防止、月間上限、キャンセル待ちの自動繰り上げ、ノーショーペナルティ判定について自動テストを用意しています。
